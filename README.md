# Kubbe-Tuki
My first ever project posted! This is a game I made in python. Hope you can enjoy!
It is about a normal platformer game being disrupted by a special crystal, which brought other games from other universes into this normal game.

The player’s goal is to stop and destroy the crystal to bring back the objects and characters back to their original game, learning different skills from other games along the way to help with his journey.

When you play this game, you can find various references to other games. Also, most of the sprites are hand-drawn, which I don’t know is a good thing or not, because I can’t draw…
